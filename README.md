# 🏠 House Price Prediction Using Machine Learning

## 📌 Project Overview
A web application that predicts house prices using Machine Learning, powered by Genetic Algorithm.

The app takes house information (bedrooms, area, floors, condition, etc.) and uses a trained model to predict the price instantly.

We use two main techniques:
- **Random Forest**: A machine learning model that predicts house prices 
- **Genetic Algorithm**: A method that finds the best features to use for prediction of house

The model runs on a **Streamlit web app**, making it easy for anyone to use without coding knowledge.
